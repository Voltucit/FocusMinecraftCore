# 开发路线

以下表格描述目标能力。当前完成工程结构及 **T01–T06：下载、版本、Java、原版安装、账号、原版启动与 P0 SDK**；T06 已补充真实 Microsoft 登录/刷新及 Windows x64 Minecraft 1.16.5 正版/离线启动验证，其他阶段等待明确安排。

T01 已完成并发、进度、哈希、超时重试、取消、临时文件替换和目录边界保护；Windows / .NET 10 下 64 项测试通过，其中包含模拟 HTTP 与本机真实 HTTP 传输测试。未验证远程 Minecraft 服务、账号或游戏进程。接口和限制见 [下载管理](downloader.md)。

T02 已完成官方版本列表、本地版本枚举、元数据解析与缓存、继承、参数合并和条件规则，共 75 项测试（原 T02 58 项、本地枚举补充 17 项），全套共 139 项通过。另已通过实际 SDK 获取官方版本列表与两个游戏版本 JSON，并验证离线继承；未安装游戏或加载器。接口与缓存语义见 [版本管理](versions.md)。

T03 已完成 Java 自动检测、自定义路径、实际运行探测、Java 8/现代版本解析、架构识别和基于版本元数据的严格选择；支持进度、取消、超时和结构化失败。新增 65 项测试，全套共 204 项通过。另在 Windows x64 实际检测 Java 8/17/18/20/25，验证缺少 Java 21 时不会使用 Java 25 替代。尚未验证其他系统或架构上的真实 Java、Minecraft 游戏启动，也不下载或安装 Java。接口和限制见 [Java 管理](java.md)。

T04 已完成客户端、Libraries、资源索引/对象、原生依赖及日志配置安装；支持阶段/下载进度、完整文件复用、中断后重试、旧版 virtual/resources 布局及安全解压。新增 64 项测试，全套共 268 项通过。另在 Windows x64 实际安装正式版 1.16.5，独立校验 2,640 个文件（401,773,932 字节）和 38 个解压文件；重复安装全部跳过，HTTP 请求为 0。未验证游戏启动、其他平台实际安装或加载器安装。接口和验证记录见 [原版安装](installer.md)。

T05 已实现调用方 Client ID 的设备码正版登录、Microsoft → Xbox/XSTS → Minecraft 资格与资料认证链、刷新令牌轮换、离线 UUID、多账号保存/切换/删除/默认设置及统一启动身份。新增 77 项测试，当时全套 345 项通过；T05 阶段在线认证为 Mock，本机验证离线账号与 DPAPI。T06 后续已完成真实登录、资格/资料和刷新验证。接口、安全存储契约见 [账号管理](authentication.md)。

T06 已实现 `MinecraftLauncher`、强类型配置、新旧版参数、Classpath/规则/资源/独立 natives、实例锁、进程管理、stdout/stderr 令牌过滤、退出监听与停止。补充 Downloader 默认入口/校验、GameCoreUtil、JavaUtil、Installer 校验/修复和离线便捷登录，原签名保留。新增 57 项测试，全套 **402 项通过**；仅引用 FMCore 的独立调用方另验证全部 P0 入口，真实校验 2,640 个文件、零下载修复，并实际用正版和离线身份启动 1.16.5。未测试世界、联机、其他实机平台、其他版本实际启动或加载器。见 [SDK 清单](sdk.md)、[启动示例](launch.md)及 [验收记录](validation/t06-p0.json)。

## P0：原版安装与启动闭环

| 模块 | 目标能力 |
| --- | --- |
| 版本管理 | 官方版本列表、版本 JSON、正式版与快照版、版本继承 |
| 游戏安装 | 客户端 JAR、Libraries、Assets、原生依赖、日志配置 |
| 下载管理 | 并发下载、进度回调、哈希校验、超时重试 |
| Java 管理 | 自动检测、兼容性检查、自定义路径 |
| 启动引擎 | Classpath、JVM/Game 参数、启动及进程管理 |
| 账号管理 | Microsoft 与离线账号、玩家 UUID、安全存储、令牌刷新、多账号 |

建议先完成版本解析和下载，再完成游戏安装、Java 检测、认证与启动。P0 需要通过真实正版账号、实际 Java 和游戏进程验证。

## P1：实例、模组和维护能力

| 模块 | 目标能力 |
| --- | --- |
| 实例管理 | 创建、删除、隔离实例及独立配置 |
| 模组加载器 | Fabric、Forge、NeoForge、Quilt 的安装与启动 |
| 完整性检测 | 检查缺失、损坏文件并按需修复 |
| 日志管理 | 实时输出、崩溃日志、错误诊断、退出码 |
| 开发者接口 | SDK、CLI、异步任务、事件、结构化错误码 |

开发者接口规范随 P0 设计，P1 完善公开入口和命令行能力。各加载器分别验证，不以其中一种通过代表全部支持。

## P2：资源、整合包与便利功能

| 模块 | 目标能力 |
| --- | --- |
| 资源管理 | Modrinth/CurseForge 下载、Mod 安装与更新 |
| 整合包管理 | 导入、导出、安装和更新 |
| 高级设置 | JVM 参数、内存、分辨率、自动进入服务器 |
| 运行环境安装 | 自动下载和安装匹配的 Java Runtime |

外部服务所需的应用注册、API Key、账号和授权条件，在对应功能实现时明确说明。整合包支持的格式和更新冲突策略也在该阶段确定。
