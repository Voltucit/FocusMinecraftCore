# 开发路线

本页保留 T01–T14 的历史开发和验证记录，已实现内容并入 1.0.0。历史段落中的“尚未发布”仅指该阶段当时状态；当前公开版本以 README 的 Release/NuGet 链接为准。T09-B Quilt 按用户决定取消。

以下表格描述目标能力。当前完成工程结构及 **T01–T06：下载、版本、Java、原版安装、账号、原版启动与 P0 SDK**；T06 已补充真实 Microsoft 登录/刷新及 Windows x64 Minecraft 1.16.5 正版/离线启动验证，T07–T09、T11–T14 已在后续完成，Quilt 已取消；本轮执行 T10 开发体验完善。

T01 已完成并发、进度、哈希、超时重试、取消、临时文件替换和目录边界保护；Windows / .NET 10 下 64 项测试通过，其中包含模拟 HTTP 与本机真实 HTTP 传输测试。未验证远程 Minecraft 服务、账号或游戏进程。接口和限制见 [下载管理](downloader.md)。

T02 已完成官方版本列表、本地版本枚举、元数据解析与缓存、继承、参数合并和条件规则，共 75 项测试（原 T02 58 项、本地枚举补充 17 项），全套共 139 项通过。另已通过实际 SDK 获取官方版本列表与两个游戏版本 JSON，并验证离线继承；未安装游戏或加载器。接口与缓存语义见 [版本管理](versions.md)。

T03 已完成 Java 自动检测、自定义路径、实际运行探测、Java 8/现代版本解析、架构识别和基于版本元数据的严格选择；支持进度、取消、超时和结构化失败。新增 65 项测试，全套共 204 项通过。另在 Windows x64 实际检测 Java 8/17/18/20/25，验证缺少 Java 21 时不会使用 Java 25 替代。尚未验证其他系统或架构上的真实 Java、Minecraft 游戏启动，也不下载或安装 Java。接口和限制见 [Java 管理](java.md)。

T04 已完成客户端、Libraries、资源索引/对象、原生依赖及日志配置安装；支持阶段/下载进度、完整文件复用、中断后重试、旧版 virtual/resources 布局及安全解压。新增 64 项测试，全套共 268 项通过。另在 Windows x64 实际安装正式版 1.16.5，独立校验 2,640 个文件（401,773,932 字节）和 38 个解压文件；重复安装全部跳过，HTTP 请求为 0。未验证游戏启动、其他平台实际安装或加载器安装。接口和验证记录见 [原版安装](installer.md)。

T05 已实现调用方 Client ID 的设备码正版登录、Microsoft → Xbox/XSTS → Minecraft 资格与资料认证链、刷新令牌轮换、离线 UUID、多账号保存/切换/删除/默认设置及统一启动身份。新增 77 项测试，当时全套 345 项通过；T05 阶段在线认证为 Mock，本机验证离线账号与 DPAPI。T06 后续已完成真实登录、资格/资料和刷新验证。接口、安全存储契约见 [账号管理](authentication.md)。

T06 已实现 `MinecraftLauncher`、强类型配置、新旧版参数、Classpath/规则/资源/独立 natives、实例锁、进程管理、stdout/stderr 令牌过滤、退出监听与停止。补充 Downloader 默认入口/校验、GameCoreUtil、JavaUtil、Installer 校验/修复和离线便捷登录，原签名保留。新增 57 项测试，全套 **402 项通过**；仅引用 FMCore 的独立调用方另验证全部 P0 入口，真实校验 2,640 个文件、零下载修复，并实际用正版和离线身份启动 1.16.5。未测试世界、联机、其他实机平台、其他版本实际启动或加载器。见 [SDK 清单](sdk.md)、[启动示例](launch.md)；详细验收记录保留在维护者本地。

T07 已在当前源码实现实例创建、列表、读取、更新和安全删除；独立配置持久化，共享版本/依赖/资源，启动准备和运行时互斥，过时快照检测及删除取消重试。新增 49 项测试，Windows 全套 451 项通过，包含独立 SDK 子进程、模拟游戏和路径链接边界。尚未发布此功能的 NuGet 版本，未新增真实游戏或 Linux/macOS 实机验收；见[实例管理](instances.md)。

T08 已在当前源码完成：复用安装/资源/原生读取规则检查与按需修复，并补充解压后的原生文件校验；Logging 提供启动器/实时游戏日志、脱敏快照、当前会话报告候选和证据诊断。新增 54 项测试，全套 505 项通过，20 段示例编译通过；测试使用真实文件/子进程和模拟游戏/下载，未新增真实游戏或跨平台实机验收。尚未发布新 NuGet，见[完整性](integrity.md)与[日志诊断](logging.md)。

T09 最初分为 A Fabric → B Quilt → C Forge → D NeoForge → E OptiFine。按用户后续指令，**B Quilt 已取消且新增文件已删除**；A、C、D、E 分别完成。T09-A 已在当前源码完成 Fabric Meta V2 查询、稳定版自动选择、完整安装、SHA-1 补齐以及既有启动/实例/检查集成，新增 41 项测试，全套 546 项通过，23 段文档示例编译通过；Windows x64 真实验证 **Minecraft 1.16.5 / Fabric Loader 0.19.5 / Java 1.8.0_482 / 离线身份**，音频/纹理和窗口初始化后由 SDK 停止。首次新增 8 个依赖，复用 2,640 个原版文件；检查 2,686 个文件通过，再次安装零下载/HTTP。未验证正版 Fabric、Mod、世界、联机或其他平台。尚未发布新 NuGet；此处保留 A 的历史验收，下文补充 C–E，见 [Fabric](fabric.md)。

T09-C–E 当前源码已实现官方版本查询、真正的安装器/处理器执行、生成文件统一校验、继承启动及简洁公开 API。新增 28 项测试，全套 574 项通过，30 段示例编译通过；Windows x64 真实离线验证 **Forge 1.16.5/36.2.42/Java8、NeoForge 1.20.4/20.4.253/Java17、OptiFine 1.16.5/HD U G8/Java8**，均在窗口/音频/纹理初始化后 SDK 停止，重复安装零下载/SDK HTTP。其他组合/平台、正版 Mod 启动、世界和联机未验收；不宣称全部旧版支持。见 [Forge](forge.md)、[NeoForge](neoforge.md)、[OptiFine](optifine.md)。

T11 分两次实施，第一部分当前源码已完成 Modrinth：按 Minecraft/加载器查询、大小/SHA-512 校验、必要依赖、重复/冲突、来源记录、更新检查与事务替换，未改变已有 API。新增 74 项测试，全套 648 项通过；真实接口另完成 1.20.4/Fabric/Mod Menu 9.2.0 及两项必要依赖的下载、独立哈希核对和重复复用，没有新增携带 Mod 的游戏启动验证。当前尚未发布新 NuGet；此段保留第一部分历史验收；第二部分记录见下文，见 [Modrinth](modrinth.md)。

T11 第二部分当前源码已完成 CurseForge 查询、完整分页、按目标环境选择、调用方 API Key、分发限制、必要依赖、来源及安全更新。复用两平台实例上下文和事务恢复；新增 82 项测试，全套 730 项通过。没有提供合法 Key，本轮全部 CurseForge HTTP 为模拟，真实 API、权限和 Mod 游戏启动尚未验收。现有 API 保留，仅新增 InstalledMod.Source 的 init 和两个末尾错误码。本功能尚未发布新 NuGet，见 [CurseForge](curseforge.md)。
