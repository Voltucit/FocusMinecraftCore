## 当前开发位置

MinecraftInstaller 的原版 1.21.10 安装与真实启动已由用户验收；选择 BMCLAPI 后的安装与真实启动也已验收。在线正式版及快照列表查询已通过 CLI 验收。下载进度已改为最近约 5 秒速度，文件数量与字节百分比分开显示，本地下载、混合复用和全部复用样本已验收。

安装和补全不再要求 JavaPath，按可选目标系统架构选择依赖；Java 在启动时指定。原版 1.8.9 已完成客户端、依赖及 4 个旧式原生库归档的元数据验收：36 个请求齐全；不能据此声称旧版完整安装均已实测。

1.21.10 Fabric 曾连续两次校验复用 4476 个文件。1.16.5 样本已用于资源补全，完整启动仍按用户决定暂缓。新版参数搭配旧式 natives 的启动兼容尚未交付。

JavaInstaller 已提供 Windows x64 官方运行时安装，用户已按 Java 25 安装并使用新运行时启动 1.21.10 的步骤反馈成功。Microsoft 正版登录已接入真实启动，用户已反馈登录并打开游戏成功；Client ID 由启动器作者提供。可选缓存接入与授权恢复已交付，用户已确认同一进程中将缓存导入第二个验证器后恢复成功；跨进程存储、加密及账号管理由启动器作者实现。下一项为 Yggdrasil 外置验证，使用 LittleSkin 验收，代码与真实登录启动尚待完成。当前已交付入口见 [公开 API](public-api.md)与[原版安装](installation.md)。

## 长期要求

- 查询只读；写入操作由启动器指定根目录，SDK 自动创建必要目录并处理失败恢复。
- 新建隔离实例放在 `versions/<版本或实例名称>/`；启动版本 ID 与工作目录名称分开，公共 assets、libraries 可共享。
- 已有外部游戏目录保留结构，不通过关闭安全检查实现兼容。
- 列表查询与单项查询分开，返回强类型对象；耗时功能提供异步和取消，简单与高级调用复用实现。
- 不自动决定账号、Java、内存、安装位置；不默认全盘递归 Java 搜索。
- 加载器自动安装范围不包含 LiteLoader；不实现基岩版检测和启动。未知加载器已有版本的读取与未来通用启动能力，与内置安装器支持范围分别管理。
- 逐步补充 launcher_profiles.json 与 launcher_accounts.json 的安全只读解析，不擅自导入或暴露令牌。
- 整合包按内部标准清单识别 ZIP/mrpack/CurseForge，普通实例导出只包含可确认来源及分发权限的内容；整包更新与单个 Mod 更新使用独立入口。
- 每阶段完成时交付公开 API、中文文档、独立可运行示例、测试证据和限制。后续 API 变更同步更新。
- 本地工具和验证材料不公开；构建通过不等于授权正式发布。

## 保留的验收边界与后续项

- 下载正常并发、复用、503 恢复和次数上限、大小及 SHA-1 校验、备份修复已验收。
- 批次取消、总超时、清理失败和回调异常仍缺少单独运行结果；不将正常反馈当作故障路径证据。
- 镜像安装成功不代表每个节点、HTTP 状态和回退分支都已单独验收。
- 单文件分段 Range 尚未实现；按实际需求决定是否开发，不作为当前 Java 安装的前置步骤。
- 原版安装不安装加载器、Java 或 Mod；JavaInstaller 已单独提供运行时安装，账号相关能力继续在第 4 阶段交付。
