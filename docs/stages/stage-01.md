# 第 1 阶段：本地版本查询

状态：已完成；Python 阶段完成于 2026-10-24，2026-10-25 按相同行为迁至 C#。

交付模型 MinecraftVersion 与 MinecraftVersionReader 的目录、列表、单版本、继承链和启动入口查询。保留多根目录汇总、同实际根去重、重复 ID 诊断、同根父版本、循环检测和只读查询。

C# 增加可取消的 GetVersionsAsync、GetVersionAsync；同步入口共用相同解析逻辑。接口详见[公开清单](../public-api.md)，独立调用见[示例](../../examples/README.md)。

验证包括内存模型、临时文件系统、JSON 异常、跨根父版本约束、同步/异步一致性和取消；另读取本机真实原版元数据。上述结果不代表依赖完整、所有自定义加载器兼容或游戏可启动。
