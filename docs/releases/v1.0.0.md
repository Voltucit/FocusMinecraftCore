# FocusMinecraftCore v1.0.0

FocusMinecraftCore（FMCore）1.0.0 是面向 .NET 启动器开发者的 Minecraft Java 版启动核心 SDK。核心保持一个业务类库，不依赖 GUI 框架，不强制 DI，程序集名称与命名空间继续使用 FMCore。

## 核心功能

- 下载与校验：单文件/并发批量、进度、取消、超时重试、哈希校验和安全原子替换。
- 版本与 Java：官方/本地版本、元数据继承与规则、本机 Java 探测和兼容检查，Temurin / Zulu Windows Runtime 查询与显式安装。
- 安装与账号：原版客户端、依赖库、资源、natives 和日志配置安装/修复；Microsoft 设备码授权、资格/资料、刷新及离线身份和多账号管理。
- 启动与维护：强类型配置、实例隔离、进程状态/日志/退出/停止、完整性检查、脱敏日志及证据诊断。
- 加载器与资源：Fabric、Forge、NeoForge、独立 OptiFine；Modrinth / CurseForge 查询、Mod 依赖安装、来源和单项事务更新。
- 整合包与高级设置：mrpack v1 / CurseForge manifest v1 导入/安装/导出、整包计划/更新/回滚/确认清理；窗口、服务器及独立堆与 JVM/游戏参数。

## 安装

```powershell
dotnet add package FocusMinecraftCore --version 1.0.0
```

运行和开发目标为 Windows 10/11、.NET 10、C# 14。需要与目标 Minecraft 元数据兼容的 Java，以及相应官方网络服务。账号、Java 主版本和内存预算由宿主决定，启动不会擅自下载 Java。

中文文档：[开发者手册](https://github.com/Voltucit/FocusMinecraftCore/blob/v1.0.0/docs/sdk.md)、[独立功能示例](https://github.com/Voltucit/FocusMinecraftCore/blob/v1.0.0/docs/examples.md)、[完整启动器项目](https://github.com/Voltucit/FocusMinecraftCore/blob/v1.0.0/docs/sample-launcher.md)。

## 验证与兼容性

修复 Windows 长路径前缀导致 Java 安装目录误判的问题，保留原有目录边界及哈希/事务校验。

发布前在 Windows x64 执行公开/本地 Release 构建、全部自动化测试、独立包调用、CLI 和示例编译。自动化协议测试中的 Microsoft、CurseForge 和部分加载器产物使用 Mock；真实文件、哈希、锁和子进程行为单独验证，不把 Mock 当作在线服务验收。

历史实际游戏范围包括 Minecraft 1.16.5 原版正版/离线，以及文档所列 Fabric 1.16.5、Forge 1.16.5、NeoForge 1.20.4、OptiFine 1.16.5 的离线组合。完整控制台示例在 Windows x64 / 1.16.5 / Corretto 8 / 离线身份下运行，观察音频和纹理初始化后由 SDK 停止。Java Runtime 实际安装范围为 Temurin/Zulu 21 JRE x64。其他游戏/加载器/Java 组合仍需单独验证。

保留既有公开类型、方法和枚举值，新增 API 详情见[兼容说明](https://github.com/Voltucit/FocusMinecraftCore/blob/v1.0.0/docs/api-changes.md)。程序集版本与文件版本为 1.0.0.0；PackageId 保持 FocusMinecraftCore。默认 User-Agent 联系链接改为规范仓库地址，默认启动器版本字符串改为 1.0.0。

## 必要注意事项

- Microsoft 正版登录需要开发者自己的合法应用注册、服务权限和玩家明确授权；离线身份不提供正版资格或服务器访问权。
- CurseForge 需要调用方合法 API Key，真实 API 权限/下载尚未验收，不绕过项目分发限制。
- Quilt 未适配；OptiFine 混合 Forge/NeoForge 安装未实现。资源包/光影可查询，安装器当前仅处理 Mod。
- 批量更新检查不修改文件；逐项 Mod 更新是独立事务，没有跨项目原子批更或单 Mod 历史回滚。整包更新/回滚使用独立包级事务入口。
- 整合包实机验证主要覆盖内容、文件哈希、更新/回滚/导出；不代表真实整合包游戏、世界或联机已验证。备份仅在用户确认正常使用后清理，清理后无法回滚。
- CLI、测试、内部日志和验证报告仅留在维护者本地，不进入公开仓库或 NuGet。
