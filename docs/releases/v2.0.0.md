# FocusMinecraftCore 2.0.0

面向 Minecraft Java 版启动器的 C# 核心。使用 .NET 10，当前游戏安装与启动面向 Windows。本文件是待发布说明。

## 这一版带来了什么

- 填好 `LaunchConfig`，调用 `MinecraftLauncher.LaunchAsync()` 即可启动，按需接收进度和游戏日志。
- 下载原版、补全文件、检查下载内容，修复坏文件前保留备份。
- 选择官方、BMCLAPI 或自己的下载源。
- 查找和安装 Java，登录 Microsoft 或外置账号，按需恢复登录。
- 安装 Fabric、Forge、NeoForge 和 OptiFine。
- 搜索 Modrinth 的模组、资源包、数据包、光影和整合包，获取作者、图片、版本、中文分类并下载文件。
- 单独检查文件和启动设置，返回具体问题。

## 最短启动示例

```csharp
using FMCore.Accounts;
using FMCore.Launch;

LaunchConfig config = new()
{
    Account = OfflineAccount.Create("Steve"),
    GameCoreConfig = new() { Root = ".minecraft", Version = "1.21.10" },
    JavaConfig = new()
    {
        JavaPath = "C:/Java/jdk-25/bin/java.exe",
        MaxMemoryMb = 2048
    }
};

var launcher = new MinecraftLauncher(config);
int exitCode = await launcher.LaunchAsync();
```

这里假定游戏已安装。Java 路径、账号、内存和目录由启动器选择。方法等游戏退出后返回退出码，不是打开主菜单时立即返回。

## 升级和使用范围

2.0 与 1.x 调用不兼容，请按[当前文档](https://github.com/Voltucit/FocusMinecraftCore/blob/v2.0/docs/README.md)接入。

Microsoft 应用 Client ID、账号保存和加密、Mod 安装管理以及整个整合包系统由启动器作者提供。CurseForge 暂未接入。

已实际运行过所选原版和加载器版本，以及 Microsoft、LittleSkin 登录与恢复流程；不表示所有游戏和 Mod 组合都兼容。新版参数与旧式原生库组合（如当前 1.16.5 样本）、部分旧资源存放方式尚未支持，也没有真实 x86、ARM64 游戏运行结果。
